# Atlas_Recruitment_Person_Detection

This repository contains a small aerial person detection dataset and the corresponding project deliverables.

## Dataset Sources
Images were collected from:
- **Small Object Aerial Person Detection Dataset**
- **VisDrone Dataset**

All images were annotated with a single class (`person`) and exported in YOLOv11 format.
